## 发布维护

```sh
npm run visuals:build
npm run visuals:verify
npm run visuals:gallery
# 实际看图和核对正文，更新逐图报告
npm run visuals:review
npm run visuals:approve
npm run visuals:promote
npm run test:site
npm run visuals:published
```

生成只写候选，不直接改正式资源。GitHub Pages的CI核对已发布文件、来源和逐图报告；图、对应正文或规格变化后必须重新验证和复审，不能沿用过期记录。提交的SVG、HTML和ZIP部署不依赖本机绘图运行库。

本次验证的是图形内容、布局、文件投影与站点显示。未将缺失的上游canonical工程、真实模型实验、企业集成、生产有效性或学习者接受列为已完成。
