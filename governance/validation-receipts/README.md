# 真实验证与学习研究收据契约

这些文件是外部验证的**收据模板**，不是已完成结果。所有模板都必须保持 `execution_status: NOT_RUN` 和 `outcome: NOT_RUN`，直到在授权环境中执行并由相应 owner 复核。执行时应复制模板为带日期和不可变输入 hash 的新收据；失败、`UNKNOWN`、分歧和退出条件都必须保留。

晋级边界：真实模型运行只支持 `model-integrated`；真实/等价企业集成运行才可支持 `integration-tested`；独立从业者盲评和目标学员研究分别支持其各自结论；生产观察和回滚演练才可讨论 `production-validated`。任一收据缺失不得越级。
