# TD-W03 单 Agent 与多 Agent 的公平实验 research brief

**Controlling question:** 怎样在相同模型、任务、总 Token、工具、重试和人工干预预算下比较单 Agent 与多 Agent，避免把更多资源误写成架构收益？

- Professional decision: 架构负责人只在实验 manifest 可比、重复运行分布显示超出噪声的收益、blocker 不增加且单位成功成本可接受时采用多 Agent；否则保留单 Agent 或 UNKNOWN。
- Work object: 固定研究任务集、single-agent arm、multi-agent arm、相同模型与只读工具、总 Token/时间/重试/人工干预预算、逐次结果与协调失败。
- Evidence boundary: all learner execution is deterministic offline fixture; model, browser, external tool, queue, live traffic and practitioner review are NOT_RUN.
- Stop rule: any missing version, permission receipt, independent Oracle, named fault, rollback owner or opened source blocks promotion.
