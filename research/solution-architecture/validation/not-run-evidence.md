# NOT_RUN evidence boundary

This artifact is deliberately not a success receipt. It records that the referenced integration, security, performance, reliability, operations, rollback, learner-transfer or practitioner gate has not been executed in a controlled external environment. A trace may reference `NOT_RUN` only when the owning solution unit remains `not-run` or `desk-researched`. It cannot support `fixture-tested`, `integration-tested`, `live-tested`, `pilot`, `public` or practitioner claims.

Closing a `NOT_RUN` gate requires an exact command, working directory, versioned environment, input and configuration hashes, observed assertions, result hashes, named reviewer and the relevant external adapter or human authority.
